# 六物品任务的可靠性与执行连续性

验证范围：主助手直接完成，不使用子 agent。沿用在线模型、RGB-D 测量、动作技能与 MuJoCo 刚体接触链路。不能用场景真值生成抓取坐标，不能降低落稳、支撑、完整轮廓或碰撞检查标准。

## 验收任务

1. 六件物品随机摆放，全部回各自默认区域。
2. 实际抓放梨子到黄色方块，再单独命令黄色方块到黄色区；检查上层依赖与暂放/复位义务。
3. 实际完成同样叠放，再命令六件物品回默认区域。
4. 六件物品随机摆放，全部回抓取区；已满足目标的物品应跳过。

随机布局固定种子、记录坐标及初始观测；叠放任务使用声明的固定布局，叠放必须真实执行。最终结果逐件检查物理状态，不能只判断模型的 finish 或网页状态。

## 已定位机制与修复方向

- 规划与驱动使用同一关节限制，并让计算取消传到迭代逆解。
- 台面曲面抓取的大幅夹持开度变化同样需要两帧视觉位置反馈。
- 经过源点云验证的球面核心可以解释搬运后新露出的自身背面；曲面包围箱空隙仍保留外物。
- 直线经过不可达中间姿态时，可选择经过真实 FK 扫掠检查的关节路径；执行所检查的关节解，起点或开度改变则拒绝。
- 叠放规划同时选择可达且开爪后无碰撞的退出路径，释放前再按实际关节与位姿复查。
- 新受检视角须留有足够计算额度处理其观测。真实仿真按工作线程计算时间计费，另有墙钟上限与停止检查。
- 相机逐项核验保留每项的对应检测身份，不从最后一张图重建前面目标身份。
- 场景修订未变时保留无关物品的核验证据，每次复用仍重新检查物理落位/支撑。搬动物品及依赖它的叠放目标失效，人工扰动或意外位移使旧场景证据失效。
- 局部裁剪不能否定图像外完整的旧源测量；真实抓取前仍执行新的局部确认。无法可靠识别的目标暂缓，最终清单不缩小。
- 台面上的锥形截面也检查双指高度，检查范围包含实际可能倾斜的抬升姿态。深度噪声产生的轻微平面坡度不使用锥形物品的观察约束。
- 空爪观察同样检查关节路径，刚释放物品的受测变换产生临时避障包络，不把它作为视觉完成证据。两片夹指和掌部分别检查，圆形物体沿用圆形轮廓。
- 上层物品盖住底座顶面时，可使用实际测得的有色竖直平面判断底座身份，结合物品库高度提出支撑层假设。角点按法向分面；下层仍是不完整、不可抓取的观测，最终仍需独立物理支撑检查。
- 几何可达但当前画面被裁剪的目标可改用受检的关节相机视角，取得新图像后才核验；不把不可达的理想光学位姿当作已到达。
- 区域搜索先兼顾不同位置与不同局部范围，再细化姿态和窄缝；严格规划尊重共享区域的分散落位设置。
- 复位朝向按几何对称性检查：轴对称直立物品不以不稳定的图像主轴判失败。位置、完整区域轮廓、支撑与静稳仍必须满足。
- 主目标明确、非目标障碍物没有指定最终安排时，模型可提出安全暂放加主目标搬运的完整方案，交既有审批流程确认；不必先用澄清问答中断任务，也不擅自恢复已经由新指令改变的旧叠放关系。
- 锥形接触约束覆盖观察后回程；两帧测到释放前平移后，可进行一次完整受检的局部重新落位，再次测量才能开爪。低位离台检查不允许水平拖动。
- 按物品保存落位瞄准提示，不能因后续搬运而忘记早先待审核目标；提示与相机核验分开。

## 记录

`cube_task.tools.assistant_bench` 保存模型轮数、完整目标、物理结果、失败、暂缓、采集帧、扫描、授权与实际耗时。原始对话、检查点和调试数据留在被忽略的本机目录；对外报告仅包含去除私人内容的统计。隔离验证场景预授权临时腾挪，但保留生产审批链路及次数统计。
