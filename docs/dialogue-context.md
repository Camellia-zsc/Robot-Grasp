# 简短回复与对话上下文

模型每次收到最近四轮已完成对话的语义摘要。例如上一轮问“愿意改放红色区域吗？”，下一轮回复“愿意”时，会同时收到这个问题。每条摘要最多 400 字，界面的实时原始输出不作为历史重新提交。

历史只帮助理解指代。物品、坐标、夹持状态和任务是否完成仍以当前观测及反馈为准；新指令可以建立新目标。“重置场景”保留可见聊天，但清空供模型使用的历史边界。风险操作仍使用当前方案的确认按钮，历史中的同意不会代替它。

对话摘要会随新指令一起发送给当前配置的在线模型，不包含 API 密钥或本机配置；可识别的密钥片段会隐藏。无需付费调用的回归：

```powershell
cd ws\src\cube_task
python -m pytest -q test/test_assistant_conversation.py
```
