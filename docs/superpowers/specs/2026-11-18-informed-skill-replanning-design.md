# 有依据的技能重规划与主动局部观察

延续用户已批准的基本技能组合、任意可达落点、多物品腾挪和人工风险确认。当前用户要求修复再次失败并扩大模型能组合的操作范围。本次现场绿色方块已夹持，首轮释放搜索消耗计算预算后，模型的第五份计划只包含原地观察；程序未告知剩余计划预算，观测后任务结束。

保留七个通用技能，将观察扩展为可指向语义目的地的静止或主动局部观察。主动观察复用真实夹持测量、手眼标定、安全视角生成、完整扫掠和 IK 预检，仅通过检查的相机运动才能执行；观察不允许释放物品。旧的无参数观察行为保持兼容。

每轮向模型说明执行器真实支持的技能、观察方式、语义目的地和剩余预算。失败历史保留详细诊断，局部观察不能把尚未解决的抓放失败替换为泛化的“任务未完成”。模型可选择暂放、重新观察、依次腾挪多件物体、重新抓取、恢复原位，再完成原始目标；这些步骤继续使用相同的技能和严格检查，不为单个颜色或特定场景添加恢复宏。

规划预算按目标数和计划长度有限调整，总技能步数仍受限；连续无信息或物理进展也有独立上限。刷新时间戳和场景编号不算进展。原始最终目标、人工批准、复位承诺、停止状态和最终相机核验继续有效。

释放搜索分配有限的阶段预算，首轮有限候选之后仍能进行纯几何容量预查和安全主动观察。几何容量结果不能直接作为可执行释放计划；实际释放仍须新鲜 RGB-D、完整足迹、手指/掌部及可达路径检查。
