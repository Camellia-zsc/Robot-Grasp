      支持哪些指令？

      可一次指定一个或多个物品：三色方块、苹果、香蕉或梨。机械臂逐件搬运，不会同时抓多个。水果先从物品库拖入抓取区；每类最多一件，桌面最多六件。

      可指定红、绿、黄色区域，例如“把香蕉放到红色区域”。未指定时苹果进红区、梨进绿区、香蕉进黄区，方块进同色区域。

      多物品可说“依次把苹果和香蕉放到红色区域”，或“把所有物品放到各自默认区域”。按清单顺序执行，逐件使用最新相机观测重新确认目标，缺失或存在歧义时停止。

      正常批量任务仅请求一次模型生成计划；异常时逐件请模型恢复，每件最多尝试 3 次，失败即停止后续物品。清单进度、恢复过程及模型实时回复会显示在界面中。

      提问只读，例如“香蕉在哪里？”或“桌上有苹果吗？”。“拿起”会执行完整抓取与放置，不会停在夹持状态。暂不支持堆叠、单件反复搬运多次、关节运动指令。

      停止/重置使用按钮。停止会中止恢复流程；输入“停止”不能打断正在执行的任务。
