# 有依据的技能重规划实施计划

**目标：** 修复持物失败后重复原地观察、五轮过早结束和首轮搜索挤占观察时间的问题，让模型能用真实能力与反馈组合多步处理。

**结构：** 协议与控制器负责能力说明、目标及预算；独立主动观察模块负责安全相机运动；执行器负责语义目的地解析；释放规划负责分阶段计算。沿用 Python、RGB-D、现有 L1 和网页，不增加模型服务。

1. 用本次只读现场记录和小型协议回归重现失败，保存不含私有聊天的诊断结论。
2. 扩展 observe 的 mode/destination 字段、能力和预算上下文；保留关键失败诊断；增加按任务规模有限扩展与无进展限制的回归。
3. 实现主动局部观察：测量持物、生成视角、扫掠与 IK 预检、逐段干预/停止检查、新相机帧融合、如实反馈信息变化；保持静止观察兼容。
4. 将首轮释放候选、容量预查和主动观察分配独立有限计算资源；禁止使用未做可达性检查的容量结果驱动动作。
5. 串行运行真实相机/IK 现场和多步恢复验收，运行相关快速协议、停止及界面回归，独立审查固定目标与人工确认边界。
6. 分功能提交、推送并更新本机服务；更新前后逐项核对物体/夹持/聊天/任务，不能无声重置或自行批准风险步骤。
