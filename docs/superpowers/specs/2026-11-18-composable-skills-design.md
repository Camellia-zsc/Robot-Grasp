# 可组合机械臂技能与整桌干预

用户已要求实现上一轮提出的基本技能组合架构，并修复人为干预只能放到抓取区的问题。本轮沿用已确认的 L1 仿真与在线 API，不增加模型服务或物理引擎。

根据同日后续澄清，普通编辑和运行中干预的俯视图均覆盖完整桌面，人工摆放不受抓取区、放置区或跨区边界限制；后端校验完整桌面支撑、邻物间隙、未夹持及场景版本。机械臂目标点选择和特定任务的区域落位核验保持独立；桌面可摆放不代表机械臂一定可达。

默认模型接口从恢复宏编号切换为技能计划：观察、抓取保持、放置、搬移、验证、询问、结束。模型可重复操作同一物品、安排多个障碍和原位复位；不会因其流程没有对应宏编号而拒绝。原始最终目标在首份计划后锁定，后续反馈只改变实现步骤。模型输入为相机结构化测量、持物反馈、原始测量位置、已执行步骤及失败原因，当前不宣称直接图像理解。

模型只使用语义目的地：最终目标、已有区域、抓取区、自动寻找空位、任务起始观测位置。坐标、抓持截面、完整支撑、夹爪扫掠、IK 和执行路径由本地规划器计算。自动空位按桌面与机械臂工作域采样，不依赖少数固定暂放点；采样与基本技能有限，不宣称完备规划或自动创造推挤、堆叠等新技能。

控制器逐步执行并公开显示计划与反馈。正常计划一次模型请求；执行失败、环境改变或计划尚未完成时，携带反馈重新规划。限制单份计划 24 步、整次任务 64 个执行步骤、最多 5 份模型计划；达到预算保持现场并说明未完成事项。停止始终优先，不能被规划或确认绕过。

模型可主动询问；本地还强制对非原目标物品搬动、原目标临时改放等有影响的步骤进行方案确认。确认列出实际步骤，绑定请求与场景，不能从模型文本推断同意。外部干预使已批准旧计划失效。临时搬动记录原位义务，若明确批准永久调整则如实列出影响，不将中间暂放计作完成。

最终成功需空爪、原始全部目标通过相机与独立几何核验，以及所有承诺的复位义务完成。途中失败记录持物、暂放与移动状态，可显式继续任务；不会重置现场或虚报整批完成。旧接口保留兼容原测试与已有客户端，默认网页实际使用新技能计划接口。

验证覆盖协议限制、重复物品与多障碍计划、真实抓取保持/暂放/重抓、错误与干预后的重规划、审批拒绝/过期/停止、整桌拖放和既有回归。独立测试禁网，在线模型规划质量与执行链测试分别说明；运行服务更新前保存并核对当前现场。
