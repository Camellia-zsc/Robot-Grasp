# 抓取区与桌面指定点放置验收（2026-11-17）

此前黄色夹持方向修复已先推送至 GitHub `abcedee`。本次在此基础上增加抓取区自动找空位、桌面 XY 指定点和俯视图点选，继续逐件执行并保留原目标恢复。

## 使用

- 直接发送“把苹果放回抓取区”或“依次把苹果和香蕉放回抓取区”。
- 俯视图切换“选择放置点”，点击桌面，再发送“把苹果放到选定位置”。点击本身不编辑世界，也不执行动作。
- 可明确给出基座坐标，如“把香蕉放到 X=0.33、Y=0.12 米处”。指定点以物体中心核验，容差 1.5 cm；不可行时不偷偷换点。
- 仍支持原三色区域和未指定目的地时的默认归类。支持桌面平面放置，不支持堆叠或指定高度。

## 检查机制

模型只接收实测物体表及配置边界；执行层先验证目标、版本、桌面支撑、完整旋转足迹、实测邻物及夹爪空间。指定点先增加目标视角，无法完成观测时直接拒绝，允许重选，不触发模型恢复或强制重置。部分遮挡但有测量几何的非可抓目标仍作为障碍。

机械臂调整姿态后，重新补偿测得的物体中心偏移，检查倾斜盒体、两根手指和掌体的全部角点投影及高度重叠。某个放置朝向不可达时可尝试同一点的其他朝向。恢复始终保留原点或原区域；批量完成记录采用放后实测局部位置，不排除整个抓取区。临时规划目标不写入世界固定分区，比赛原始计分保持原含义。

扩大运行旧核心测试时得到 127 通过、8 失败。另用已提交的 `abcedee` 原始 Python 模块覆盖导入、保持当前工作文件不动，重跑这 8 项，得到相同的 8 项失败，确认并非本次引入：

每个不同桌面点会保留一个相机视角，用于之后再次观察和搬走该处物品；反复尝试很多不同点会增加后续扫描耗时。当前未实现视角缓存淘汰，留作后续性能优化。

当前仍为 L1 运动学与几何反馈仿真，尚未验证接触摩擦、滑移、刚度、Gazebo 或 MoveIt2 物理闭环。
