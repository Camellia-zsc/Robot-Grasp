# 多物品摆场与抓取验收

日期：2026-11-16。运行入口仍为根目录 `启动智能抓取界面.cmd`，地址 <http://127.0.0.1:8767>。

## 已实现行为

- 六类物品：三色 50 mm 方块、球形苹果、弯曲香蕉、带颈部和果柄的梨。每类最多一件，总计六件；当前不支持用户导入任意模型或缩放物体。
- 独立俯视摆场：物品库拖入/点击放置，已有物体拖动、旋转、删除和清空；3D 场景与实时相机显示同一几何模型。
- 服务端校验场景版本、有限数值、完整足迹位于抓取区、至少 8 mm 间隙和类别数量。失败不部分修改世界；忙碌、停止待重置或仍持物时禁止编辑。
- 布局变更后清除旧检测编号、相机扫描图、占用/黑名单和恢复上下文。下一条指令重新通过 RGB-D 扫描测量，不把摆场真值填入模型目标表。
- 独立 Sandbox 任务让水果使用圆形/长条/截面规划，保留原 L1 比赛入口。显示测量尺寸、预计夹宽、实测夹宽、闭合/抬升/搬运检查和独立落位检查；自动恢复仍保留。

## 识别与抓取中的实际修复

分类使用现有 KNN，根据合成 RGB-D 中的颜色和几何特征训练。库内标签仅作为离线样本监督信息；运行分类器不接收当前编辑世界。新缓存有 81 个样本、六类，冷训练约 40–60 秒，后续从系统临时目录加载约几十毫秒。源码和模型定义变化会重建缓存，缓存不入 Git。

梨在 `(0.28, 0), yaw=0.6` 的实际腕相机图像中，原 8 mm 内部高度切分把颈部与腹部拆开。简单禁用切分又会把相机投影连接的梨和苹果合并。因此最终保留桌面 XY 空间分割，只在 Sandbox 将高度跳变阈值设为 80 mm，保留边界、遮挡、尺寸完整性和类别尺寸上界检查。精确混合布局的 RGB-D 回归中三类均有效，位置误差小于 25 mm；测试把世界标签改为假值，确保分类不使用真值标签。

梨按默认最大深度 40 mm 抓取时，果柄撞到夹爪掌部；30 mm 仍在陡肩部发生 `slip_dome`。限制梨类别最大深度为 25 mm 后，抓取高度继续由实测顶部减去深度产生，既有截面规划能在颈部夹持，未修改真值坐标或安全阈值。该类别配置同时适用于普通与截面规划分支。

## 实际在线联调

`catalog_online_validation.json` 记录一次真实在线指令“把香蕉放到黄色区域”：

| 项目 | 实测 |
|---|---|
| API 请求 | 1 次，未触发额外恢复 |
| 动作与独立落位 | 均成功，目标实际进入 `zone_yellow` |
| 测得香蕉长/宽/高 | 131.7 / 46.1 / 39.8 mm |
| 预计/闭合后实测夹宽 | 约 51.0 / 41.3 mm |
| 抬升/搬运后宽度 | 均约 41.25 mm |
| 公开回复路径 | 接收到真实模型回复，轮询观察到长度 0 → 110 |

这次在线联调在最后的混合分割修正之前完成；随后分割改动另有实际 RGB-D 与抓放回归验证。该记录不能作为任意遮挡场景都能识别的证明。

复现脚本为 `verify_catalog_online.py`。不加 `--execute` 只摆入三种水果；加 `--execute` 才发送一次正常模型指令，可能产生中转站费用。脚本只访问本机仪表盘，不读取或保存密钥。

## 回归与验收范围

- 物品库与 RGB-D 分类：30 项通过，覆盖原子拒绝、香蕉旋转中心、六类识别、梨颈腹、香蕉朝向、混合分离和大轮廓拒绝。
- 助手/服务器/恢复流程、技能、预览和反馈：170 项通过。
- 最终真实仿真回归：`test_assistant_catalog_simulation.py`、`test_assistant_simulation.py` 和 `test_assistant_recovery_simulation.py` 合计 15 项通过，耗时 483.33 秒。覆盖三种水果独立抓放、混合水果识别与香蕉分拣，以及原有助手仿真和自动恢复；使用最后的混合分割修正版本。
- 相关抓取规划与独立反馈测试：74 项通过，另排除 1 项已在发布基线复现的旧测试失败。
- Python 编译、JS 语法与 Git 差异检查通过。独立代码审查未发现阻断问题。
- 前端用模拟 DOM 检验增删、拖动、旋转、版本请求、busy 锁和复杂几何展开。真实浏览器工具因无法验证当前浏览器网址而中止，因此没有声称完成真实浏览器拖放或截图验收。

既有失败为 `test_plan_official_grasp.py::test_cube_grasp_for_50_mm_blocks`：测试硬编码最大深度 30 mm，而当前既有默认配置为 40 mm，抓取高度约 10.36 mm 不符合测试中的 20 mm 下界。在变更前的本地发布基线和新版本中均能复现；本次未修改该比赛测试。

## 限制

这是运动学与几何抓取仿真，没有接触摩擦、真实力反馈或刚度模型。编辑合法不代表任意位置、方向和遮挡都可抓；IK、夹爪空间、相机遮挡或类别尺寸检查仍可能拒绝。未知物品、任意新外观、多件同类、堆叠、连续视觉伺服和通用物体识别仍属后续工作。
