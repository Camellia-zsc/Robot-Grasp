支持哪些指令？

每次搬运一个红色、绿色或黄色方块。直接说“抓取红色方块”，默认放到同色区域。

也可指定其他区域，例如“把红色方块放到黄色区域”；可选红色、绿色、黄色区域。

提问只读，例如“红色方块在哪里？”或“桌上有蓝色方块吗？”。

执行异常时会重新检查状态，请模型给出恢复方案并验证结果；最多增加 3 次模型请求。恢复过程及实际模型回复会显示在界面中。

“拿起”会执行完整抓取与放置，不会停在夹持状态。暂不支持多目标、堆叠、关节运动指令。

停止/重置使用按钮。停止会中止恢复流程；输入“停止”不能打断正在执行的任务。
