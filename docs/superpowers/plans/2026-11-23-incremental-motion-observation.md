# 执行中增量观察与五类任务验收

由主助手直接实现，不使用子 agent。用户已指定行为与五类验收场景，按该范围实现，不增加审批环节。

**目标：** 使用运动途中实际采集的 RGB-D 更新物品和目标区状态，减少独立扫描；已被人工完成的子目标跳过，保留所有原始目标和安全检查。

**设计：** 在仿真所有者线程按限频采集，避免额外相机运动和并发操纵相机。不同相机姿态的测量统一到基座坐标；完整新测量替换旧位置，遮挡与裁剪保留旧障碍但不产生完成证据。单次动作前使用未失效的几何，下降前用途中图像确认目标；变化后在安全边界重测/重规划局部路径，不能把旧轨迹直接标成安全。最终审核复用运动途中或落稳后的完整测量，缺失时才补视角。

**备选与取舍：** 仅增加缓存时长不能发现人工干预；独立后台相机线程会争用物理/相机资源并打乱时间对应。选择所有者线程采样和按物品失效证据，保留新帧、支撑和实际扫掠检查。
