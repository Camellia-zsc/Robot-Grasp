# 大模型指令抓取与仿真界面

用户已选择方案一并要求直接实现：复用本机正在使用的中转站 API，先接通 L1 运动学仿真，在界面显示运动过程与模型实时回复。

## 范围和数据流

本地浏览器界面输入中文任务，仿真 RGB-D 感知产生物体表。在线模型根据该表选择一个物体和已有放置区，输出受约束的 JSON。本地校验场景版本、目标编号、有效深度和区域后调用现有 `TaskRunner.pick_detection`。执行完成后再次感知并报告仿真真值检查。单次任务只执行一个物体；目标未观察到或指令有歧义时不执行。

启动后保留一个仿真会话，提供慢速可见的动作与重置功能。画面展示真实仿真状态：关节正运动学、夹爪开合、物块和区域；相机缩略图明确标记为最近一次观测。运动学仿真不能用于证明摩擦稳定性，也不宣称已有 Gazebo、MoveIt2 或接触物理。

## 边界

- API 连接和流解析：`assistant/llm.py`。读取当前 Codex 配置，环境变量可覆盖；凭据只在本机读取，不进入网页、日志或仓库。兼容 Responses 与 Chat Completions。显示模型公开输出，不显示隐藏推理。
- 仿真与现有代码连接：`assistant/simulation.py`。只允许 L1 sim，使用真实 RGB-D 检测和已有抓放动作；提供缓存状态和中断，不增加真实硬件入口。
- 会话与网页服务：`assistant/server.py`。标准库 HTTP 服务绑定 127.0.0.1，单任务工作线程、取消标志、200ms 状态刷新、错误隔离。
- 可视化：`assistant/static/`。无需额外前端框架或公网 CDN。机械臂场景、中文指令、逐字模型回复、物体列表、任务状态、速度、停止和重置。
- 启动与说明：`tools/assistant_ui.py`、根目录双击启动文件及中文使用说明。

## 验收

1. 凭据加载不输出密钥；缺少配置时仍能查看仿真并显示如何配置。
2. SSE 碎片、中文、结束/失败事件正确解析；无效 JSON、旧版本、编造编号、非有限坐标均不能执行。
3. 初始 L1 能观察三个物体；合法红色目标抓取后真值发生正确变化。
4. 网页能看到真实关节/物体运动以及真实模型输出流；不将固定回复冒充在线结果。
5. 实测一次在线指令并记录去密钥的结果；验证未观察到目标时无抓取动作。
6. 重复任务、并发提交、停止、重置和接口错误有明确反馈。
