# 全体归位任务范围与完成检查

实际故障：用户要求所有物品回到默认区域，首次模型只列出香蕉和苹果两个最终目标；后续虽有人工授权和恢复动作，但最终只核验两个目标便显示全部完成。现场其他物品被遮挡或检测无效不应缩小用户任务。

选择后端任务范围约束，不仅增加模型提示，也不把动作可执行集合当成最终目标集合。明确的全体默认归位要求绑定现场清单中的全部类别与已配置默认区域；清单只包含类别和数量，不向规划器提供模拟器坐标或姿态。配置支持的全部类别不代表现场实际存在，不能直接以配置映射的所有键代替清单。

范围在首次请求和旧任务续接时绑定。保留已有目标索引，再追加遗漏目标；冲突、缺少默认区域、同类多件等不能静默忽略。被遮挡或尚无有效观测的物品仍属于待办，动作继续需要新的唯一有效相机测量。

每轮步骤可以只完成部分目标，但模型返回的最终目标必须保持完整。人工按钮只授权所列后续操作，不代表移动完成、故障解除或目标减少。最终完成检查再次验证范围覆盖与每项目标，不接受部分目标的缓存证据作为全体完成。

只处理当前可见物品、明确子集、否定要求、只读问题、原位复位与默认区域归位应保持区别。没有明确识别为全体默认归位的指令仍由现有语义规划处理，不强加全体目标。

验证顺序：先离线复现真实控制器的部分计划错误完成和旧任务续接；再覆盖批准、拒绝、现场变化、遮挡、完整计划成功和显式子集；最后对实际保存现场执行完整清单核验，备份并恢复对话及摆场，启用修复。原始对话与运行快照保存在私有诊断目录，不提交仓库。
