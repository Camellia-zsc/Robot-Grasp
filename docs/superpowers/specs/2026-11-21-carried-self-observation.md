# 持物自身遮挡与放置失败反馈

现场在红区已有苹果、机械臂夹持红块时，将二者连通的轮廓误分类为高达 186 mm 的无效梨。仅按当前类别排除 red 无法识别该跨类别自身片段；它在观察路线的起点就与持物体积重叠，因此全部路线失败。区域尚有空间时模型便提出了暂放恢复。

修复在单次相机采集内分开原始与环境测量。原始 RGB-D 继续用于真实可见性和两帧夹内位置标定；环境分割使用副本，按已执行的源抓取测量、当前 TCP 和夹爪开度去除可证明属于自身的三维表面。不能按当前分类标签或 invalid 状态整块删除障碍，不能把删去的像素变为已观测空桌面，也不读取模拟物体位姿参与规划。复杂形状的包围箱空隙须保留外物。

首次搬运的回调也显式传入其正在使用的测量抓取，而不依赖失败后才保存的恢复记录。环境列表绑定同一帧原始表面，供水果标定使用，避免另取陈旧缓存；相机采集次数不增加。

放置拒绝、几何容量三态和观察路线拒绝分别进入执行反馈。观察受阻不表示容量为零；几何容量为真也不能替代可见性、可达性、全路径碰撞和落稳检查。暂放或移动其他物品仍按现有要求由人工授权。

验证覆盖原始帧不变、混合轮廓分离、外物保护、无效几何及陈旧反馈、首次回调、夹内标定、失败反馈链路和现场 MuJoCo 重放。部署须保留持物、摆场、对话、完整目标和历史，取消过时的待批暂放方案，重新规划前不执行搬运。
