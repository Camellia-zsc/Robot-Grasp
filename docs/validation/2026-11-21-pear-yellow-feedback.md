# 梨子叠放偏移、退爪碰撞与重复扫描

## 故障复现与原因

本次诊断来自用户实际任务日志和停止后的六物品摆场。原始抓取前梨子位姿未被完整记录，因此独立回放保留其余物品、仅将梨子直立放回约 `(0.51, -0.01)` 米；这是近似重建，不能称为精确还原原始任务。所有回放使用 MuJoCo 物理后端，网络关闭；模拟器真值仅用于诊断和结果评估，不提供给视觉定位或规划。

梨子质量为 100 克，模型局部重心约为 `(0, 0, 53.178)` 毫米，未发现横向偏心。平底直径约 48 毫米，黄色方块实测边长约 48.074 毫米，小底座对误差较敏感。此次没有修改质量、重心、摩擦或重力来使结果通过。

在近似重建的旧流程中：

- 闭合时夹宽约 46.4 毫米，抬起后缩至约 38.5 毫米。梨子相对夹爪旋转约 13.30 度、移动约 18 毫米，旧刚性参考已不准确。
- 规划目标本身距离底座中心约 0.48 毫米，实际松爪后梨子底部偏离约 20.4 毫米。问题不能仅归因于落点搜索。
- 原约 68 毫米的松爪开度仍使一侧夹指与梨子接触。松爪后倾角一度约 1.03 度，随后带旋转的撤退把它推倒到约 114.28 度；这一变化发生在最终核验扫描之前。
- 独立反事实实验将开度改为 80 毫米，并在原地等待 1.2 秒，最终倾角约 0.94 度且保持黄色底座接触。此实验用于检验原因，未经生产几何检查的开度覆盖不能作为最终修复证据。

进一步的完整回放发现，单独修正夹内平移仍不足以消除放偏：融合源云的可见外框中心约为 `(0.49672, -0.00974, 0.06660)` 米，腹部球心约为 `(0.51000, -0.00998, 0.04238)` 米，水平差约 13.3 毫米。放置规划仍将可见外框中心当成放置中心，且旧落点优先级高于底座中央，造成校正后的球心仍偏约 16 毫米。这一中间版本再次倾倒，不能作为成功结果。

## 反馈与释放检查

球形腹部的中心可以从深度点云中可靠拟合，但当前遮挡下完整物体旋转不可观测。因此新增反馈只校正夹持参考的平移，保留原有旋转，不声称恢复了完整六维位姿。球半径来自已知物品类别，中心来自 RGB-D；没有读取当前模拟器物体位姿。

源位置使用已接受的融合点云。夹持后需要两个新鲜、相机基本静止、现场未变化的独立捕获；球面覆盖率、残差、法向条件和多假设一致性均通过后才更新平移参考，并保留原始抓取命令。夹宽明显变化或持物恢复缺少原始闭合记录时，不能假定夹内位置不变。释放前再次核对当前深度证据；新滑移超出 3 毫米则保持夹持，要求重规划。

叠放退爪必须先具备可执行的退出条件：同姿态竖直清离，或经完整放置几何检查的足够宽开度。受检宽开度绑定最终释放和撤退矩阵；过期或不匹配的记录不能使用，实际夹宽必须达到受检要求，随后沿预检的直线路径撤退。停止、现场变化、真实控制故障仍会终止动作。

已确认的腹部球心现在同时作为放置规划的中心参考；完整点云仍参与轮廓投影和碰撞检查。叠放优先检查底座中央，不再让带旧偏差的放置点抢先通过。首次搬运在修正参考后重新检查完整路径，持物续接复用同一套检查；保存的原始抓取命令与虚拟持物参考分开，后者不能被自动当作源位置执行。

宽开口同时检查最终释放位姿及撤退沿途的空夹爪几何，运行时再从实际释放位姿复查。开夹后保持机械臂静止 1.2 秒，再执行受检退出；等待期间的停止和人为干扰会阻止后续退出动作。这里是固定的有限等待，不代表从时间长度就能保证任意物品稳定，最终仍需视觉与真实支撑核验。

腕相机原安装点只能看到腹部窄环，且可能混入同色黄色底座。沿法兰 Z 后移 25 毫米后，场景安装位置与视觉外参同步更新，重建不会累计偏移。真实物理相机参数下，旧释放位姿的拟合球面内点约 91.5%，法向条件数约 11.3；保留原质量门槛。完整物体分类偶尔将同一梨子分成两片，因此只有已建立可信夹持跟踪时，才允许合并像素互不重叠、每片独立拟合通过且球心相差不超过 1 毫米的同语义分片。重复检测和不同球心仍拒绝。

## 重复扫描

原流程在下一帧只看见底座、梨子被裁切时，虽然保留了已接受的抓取目标，却把几何就绪状态重新算成未就绪，于是继续遍历剩余视角。修复将就绪状态绑定到保留的实测目标，找不到底座时优先检查底座相关视角。

相同重建场景的抓取前观测由六次 `[4, 5, 1, 0, 2, 3]` 减至两次 `[4, 0]`。这不是删除最终核验或放松新鲜度；夹持校准用的静止新帧和必要的底座观察仍会保留。

## 最终生产回放

首个使用完整放置修复、无开口覆盖及无诊断等待覆盖的六物品回放，已在黄色底座上稳定直立：开夹约 0.224 度、撤退约 0.227 度，额外两秒后约 0.22 度，真实接触与支撑均通过。然而该次相机核验仍返回 `placement_not_observed`，因此整体任务正确报告失败，不能称为端到端通过。

相机进一步诊断发现，原来约正向左右各 5 度的高位观察仍看不见宽梨肚下方的黄色顶面。新增依据实测底座计算的侧向低斜候选，先检查关节限制、实际相机完整投影和整条安全观察路径，再取得新的 RGB-D。它不直接发布一个成功检测，也不读取模拟器位姿来决定观察方向。固定的现场关节角没有写进生产代码。

同一保存现场的生产 `verify` 红绿回放：旧观察流程取得 5 帧仍未通过视觉核验，新流程用 3 帧取得梨子和黄色支撑面的证据，通过视觉及真实支撑核验。两组均保持原感知与成功门槛，物品没有被重新抓取。

最终从抓取开始的完整生产回放通过，起点约 `(0.51, -0.01)` 米，保留六个物品，没有诊断开口或等待覆盖，没有调用网络，也没有触发持物重试：

| 检查 | 结果 |
|---|---|
| 抓取、搬运、释放、撤退及相机确认 | 全部通过 |
| 黄色底座真实接触、稳定支撑 | 通过 |
| 最终倾角 | 约 0.23 度 |
| 最终底部中心与底座中心距离 | 约 5.2 毫米，非精确零偏差 |
| 结束状态 | 空爪、无控制故障、无停止标记 |
| 图像数 | 17 帧，包含启动时的 6 帧全景准备 |
| 目标抓取前视角 | 2 个，取代旧流程的 6 个 |
| 本样本总耗时 | 约 195 秒，不作为整场仿真加速的证明 |

必要的夹内两帧反馈是静止拍摄；核验发现支撑关系后即停止，不遍历整个桌面。它们不能与没有新增信息的重复扫视混为一谈。

偏移起点 `(0.50, 0.015)` 米的中间版本回放，在放置观察规划达到时间预算后保持夹持。一次生产 `place` 持物续接仍超时，没有松爪、重抓或控制故障。这一失败被保留并继续诊断。

后续证据确认一个通用候选遗漏：平行夹爪转过半圈后，夹持轴相同，但倾斜工具的完整三维姿态不同。旧搜索只保留轴方向的一种完整工具姿态。两个起点的源抓取朝向分别约为 `3.093` 与 `0.102` 弧度；旧落点朝向 `2.689` 弧度对前者可用，对后者预测梨体倾斜约 25 度、底部穿入支撑约 9.46 毫米，所以原检查正确拒绝了它，却没有尝试另一个朝向。

搜索现在枚举完整工具朝向的两个半圈分支，按与源抓取的完整角度差排序，并保留完整几何、姿态、IK、可见性及退出检查。偏移起点选出的约 `-0.453` 弧度朝向预测梨体倾斜约 5.07 度、底部误差约 0.31 毫米，能通过原条件。显式恢复朝向要求不会因此获得半圈豁免，旧成功起点仍选择原安全朝向。生产代码没有根据这两个现场坐标分支处理。

修复后的偏移起点完整回放也通过：实际倾角约 **0.30 度**，落稳中心偏差约 **7.1 毫米**，视觉确认与真实黄色支撑均通过，结束空爪且无故障。18 帧包含启动 6 帧；总耗时约 221 秒，仍未触发重试。至此两个起点均通过，但这两次样本不能证明任意摆场或任意水果都必然成功。
