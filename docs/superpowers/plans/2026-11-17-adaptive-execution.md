# 自适应执行实施计划

**目标：** 修复香蕉现场并支持按需观测、运行中干预、受约束模型移障恢复。

**结构：** 抓取几何留在 perception/grasp.py；观测排序与局部缓存规则独立在 assistant/observation_policy.py；session 负责传感观测与执行事务；skills 提供执行检查点；controller 保持用户目标与恢复模型协议。

- [x] 精确恢复已保存的 transform，禁网复现并记录闭爪失败机制。修改实测抓取截面/开口/邻物候选，添加真实回归。
- [x] 增加视角排序、深度可见性判断、局部观测合并与可靠目标提前停止。首次观测保留完整性；复用初始队列并在执行前重新确认。
- [x] 增加非阻塞干预队列与时钟边界应用，禁止移动夹持物品；干预版本只作为观测失效信号。增加抓取前和放置前检查点。
- [x] 放置前根据最新局部观测重新规划同一区域空位，支持区域边缘；指定点不改变坐标。放后局部核验，不再全场扫描。
- [x] 当直接抓取不可行时生成测量支持的临时移障方案，模型选编号；逐件移障、原任务、复位，明确失败收尾。
- [x] UI 增加运行中干预状态、已排队/生效反馈；保持点选和流式模型回复。
- [x] 禁网真实执行验收及必要回归，冻结源码哈希；独立审查。按功能提交并推送，保存用户最新现场后部署。
