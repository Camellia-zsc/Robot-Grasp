# 自由桌面放置实施计划

**Goal:** 物品可放回抓取区或用户选择的可行桌面点，同时保留顺序抓放、自动恢复和实时界面。

**Architecture:** 可选 `destination` 经共享模块验证；执行层使用临时规划区域与严格空间检查，固定世界分区不变。界面点选独立于摆场编辑，随一次语言指令发送。

**Tech Stack:** Python、现有 RGB-D 运动学仿真、原生 HTML/Canvas/JavaScript。

- [x] 共享目标与执行：创建 `assistant/destinations.py`，修改 `assistant/simulation.py`、`task/runner.py` 及 `perception/grasp.py`；实现 region/point 验证、严格足迹/占位、临时目标、落位反馈和重新观测。为边界/占位/精确点不漂移增加有效测试。
- [x] 模型、队列和恢复：修改 `assistant/llm.py`、`batch.py`、`server.py`、`recovery.py`；旧格式相等性保持，目标在重绑定与恢复中保留，新增点选上下文，按局部身份保护完成物品。
- [x] 界面：修改 `static/editor.js`、`app.js`、`index.html`、`style.css`；选择落点/取消、标记与坐标、请求传递、新目标文案、忙碌/重置失效规则和帮助示例；点击选择不得编辑世界。
- [x] 验证：运行新协议和执行测试、旧相关回归、DOM 交互和语法检查；独立审查跨层目标一致性、完整足迹、碰撞、计分与真值边界。
- [x] 最终源码冻结后运行实际 RGB-D/运动/反馈的新目标场景及旧六件整批，记录源码哈希，保留前后布局和失败拒绝证据。
