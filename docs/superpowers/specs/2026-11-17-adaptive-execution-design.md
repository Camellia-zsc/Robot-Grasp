# 自适应抓取与按需观测

目标是修复已保存的香蕉二次抓取失败，并让有限任务队列在场景变化时局部重定位，而不是每件物品反复全场扫描。

抓取采用 RGB-D 实测截面给出足够但较小的夹爪开口，并检查不同角度、位置候选的目标包络和邻物间隙。真正没有直接抓取方案时，只向模型提供本地检查过的临时移障选项。选项包含遮挡物原始实测位置、临时空位、原任务和复位步骤；模型只能选择方案编号。复位失败必须明确显示未恢复物品，不得把原任务成功当作整个事务成功。

首次准备完成全场观测，用户指令复用已有观测生成固定意图队列。每件执行前优先目标旧视角，可靠找到目标即停止；丢失才扩展搜索。局部新帧覆盖范围内的旧检测失效，视野外观测保留但不算新确认。放后只观察目的区域，抓走的旧目标不得从其他视角缓存复活。任意落点共用一个临时相机视角槽，不随历史指令增长。

接近目标与放置前设置执行检查点。运行中干预通过独立队列在仿真时钟边界应用，只允许移动、旋转桌面上未夹持物品；观测坐标只来自后续相机。抓取前变化则退回并重新定位，放置区变化则维持夹持、局部观测后重新选择同一区域的空位。固定点仍保持坐标，不能擅自改成另一个位置。

界面保留普通摆场及点选目的地，另设运行中干预模式，显示等待、生效、目标重定位和局部扫描。模型原始流式回复继续显示。

验收使用独立禁网仿真：精确香蕉现场、窄夹爪邻物、真正拥挤移障及复位、批量观测计数、找到即停、目标移动补扫、目的地占位变化和运行中干预。仿真真值只用于初始摆场与独立结果核验。
