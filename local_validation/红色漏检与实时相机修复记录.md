# 红色漏检与实时相机修复记录

日期：2026-11-16。修复版运行地址：<http://127.0.0.1:8766>。

## 复现与原因

原服务先成功执行“把红色方块抓到黄色放置区里”，随后执行“把红色方块抓到绿色放置区里”却报告未观察到红色。`regrasp_scan_before.json` 保留了故障状态：仿真世界的红色仍在黄色区，可选观测表只剩绿、黄。

两处原因同时存在：助手沿用了比赛中排除已放置物体的过滤规则；原有三个腕部视角主要覆盖取物区，未专门观察各放置区。旧相机接口还只返回最后一张观测截图，网页轮询不会产生新画面。

## 最终改动

- 保留相机测量到的已放置方块，以 `in_zone`、`zone` 标明当前区域。
- 在原有三个视角之外，根据已配置区域几何增加三个可达腕部视角，扫描时显示进度；没有根据物体真值选择相机位姿。
- 用当前观测重建放置占用，排除即将搬走的目标，避免旧占用阻止再次抓取。
- 缓存六个视角的检测图和时间，网页可逐个查看。
- 从独立状态快照渲染最高 3 fps 的腕部预览；不调用感知相机、不推进虚拟时钟、不改变检测随机状态。实际检测仍走原 640×480 RGB-D 流程，在扫描时更新。
- 预览渲染失败时标记不可用并允许恢复重试，不继续把旧画面标成当前可用。
