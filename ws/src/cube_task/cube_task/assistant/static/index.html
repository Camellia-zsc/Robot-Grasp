            支持哪些指令？

            可一次指定一个或多个物品：三色方块、苹果、香蕉或梨。机械臂逐件搬运，不会同时抓多个。水果先从物品库拖到桌面；每类最多一件，桌面最多六件。手动摆场可在放置区内或跨区，完整轮廓须留在桌内并与其他物品保持间隙。

            可指定红、绿、黄色区域，例如“把香蕉放到红色区域”。未指定时苹果进红区、梨进绿区、香蕉进黄区，方块进同色区域。

            “把苹果放回抓取区”会自动找空位。精确放置时，先在俯视图切换“选择放置点”，再点击桌面并说“把苹果放到选定位置”；也可明确给出桌面 XY 坐标，例如“把苹果放到 X=0.30、Y=0.08 米”。点选不会直接移动物品。

            指定点会检查桌面支撑、物品占位和机械臂可达性。空间不够或无法到达时会说明原因，不能自动换到别处；抓取区请求则可在区域内另找空位。

            多物品可说“依次把苹果和香蕉放到红色区域”，或“把所有物品放到各自默认区域”。模型会组合观察、抓取保持、放置、搬移、验证等技能；允许同一物品多次搬移，也可先移开障碍再完成原目标。改变其他物品布局或暂改目的地前需要人工确认。

            任务运行时可在俯视图切换“运行中干预”，在整个桌面拖动或旋转未夹持物品，包括抓取区以外；不能增删物品或移动机械臂正在夹持的物品。干预会在仿真步间生效，原任务随后通过相机确认变化。

            模型技能计划会显示实际步骤、当前执行位置和失败反馈。模型可根据新观测重新规划；暂放不等于完成原任务，全部最终目标需独立核验。需要人工选择时仅点击“同意执行”或“拒绝并停止”，模型回复不会代替你的确认。

            提问只读，例如“香蕉在哪里？”或“桌上有苹果吗？”。抓取保持与放置是独立技能，任务完成需空夹爪且最终落位通过核验。暂不支持堆叠或关节运动指令。

            停止/重置使用按钮。停止会中止恢复流程；输入“停止”不能打断正在执行的任务。
