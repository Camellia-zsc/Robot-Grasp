# 持物暂放、局部重排与人工确认

当前现场的香蕉仍被夹持，直接失败发生于黄区边缘的观察抬升逆运动学检查。先修复观察路径，再增加用户要求的多步恢复，避免把观察失败误报为区域容量不足。

恢复继续由模型选择本地测量支持的方案。扩展可组合步骤为：保持夹持重新观察；安全暂放并重新抓取；安全暂放、移动一件区域内障碍、重新抓取原目标。暂放点、障碍新位置、原目标最终位置均通过原有严格几何与可达性检查。指定目标与用户任务不变，不允许模型生成未经检查的关节运动或随意松爪。

持物暂放采用独立执行上下文，冻结原目标与真实抓持变换。障碍重排优先保持其所在区域，保留批量已完成目标的约束；没有符合全部约束的方案则停止。任何中途失败明确返回目标暂放位置、已移动障碍及未完成步骤，不把中间暂放当作原任务成功。

多步暂放/重排方案需在网页显示问题、步骤与影响，用户点击“同意执行”才继续。拒绝或停止不执行后续动作；确认期间现场改变使方案失效，重新观测规划。确认绑定唯一请求与场景版本，不接受陈旧、重复或默认批准。在线模型的流式公开回复继续显示。

验收包括精确现场禁网重放、不可达观察抬升的回归、真实暂放/重排/重抓、原任务与已完成目标共同核验，以及确认/拒绝/停止/过期状态测试。真值只用于初始实验摆场和独立验收，不输入规划。按功能提交并更新本机服务，保留用户现场和聊天；持物现场恢复须保持抓持变换，不能强行松爪。
